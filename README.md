

\# Character Vault



Prywatna biblioteka postaci AI.



\## Uruchomienie lokalne



1\. Pobierz wszystkie pliki projektu.

2\. Umieść je w jednym folderze.

3\. Otwórz index.html w przeglądarce.



\## Publikacja na GitHub Pages



1\. Utwórz nowe repozytorium na GitHub.

2\. Wgraj index.html, style.css, app.js i README.md.

3\. Przejdź do Settings.

4\. Wybierz Pages.

5\. W sekcji Build and deployment wybierz Deploy from a branch.

6\. Wybierz main oraz / (root).

7\. Zapisz ustawienia.



Po chwili strona będzie dostępna pod adresem GitHub Pages.



\## Przechowywanie danych



Dane są zapisywane lokalnie w przeglądarce.

Regularnie eksportuj kopię zapasową JSON.
